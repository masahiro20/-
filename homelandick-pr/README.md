# 株式会社ホームランディック PR動画

新規のお客様向けPRムービー(74秒 / 1920×1080 / 30fps / オリジナル楽曲付き)。

- 完成動画: `out/homelandick_pr.mp4`
- 映像: `src/index.html`(HTML + SVG のアニメーション。`index.html#play` をブラウザで開くとプレビュー再生)
- 楽曲: `src/music.py`(numpy による音源合成)
- 書き出し: `npm install && npm run build`(Playwright + ffmpeg が必要)
