# 太陽光 適正容量シミュレーター

お客様の暮らし方（家族構成・空調の使い方・ペット・EV/V2H・蓄電池・停電への備え）と、
地域・屋根・パネル機種から、**「何kW載せるのがベストか」を根拠付きで算出**するツールです。

- 気象庁の実測データ（全国63地点）× JPEA（太陽光発電協会）表示ガイドラインの計算式で発電量を推定
- 機器ごとの積み上げで消費量を推計（24時間空調・全館空調・エコキュート・EV など）
- 365日×24時間で自家消費・売電・蓄電池/V2H をシミュレーション
- パネルを1枚ずつ増やして20年収支を比較し、**経済性・ネットゼロ・屋根上限・停電対策**の4基準で推奨容量を決定
- お客様向けの**提案書を印刷（PDF保存）**できます

計算の考え方と数値の出典は **[docs/根拠と計算方法.md](docs/根拠と計算方法.md)** にまとめています。

## 使い方

### 起動

インストール不要です。`index.html` をブラウザ（Chrome / Edge 推奨）で開くだけで動きます。

```bash
# ローカルサーバーで開く場合（任意）
python3 -m http.server 8000
# → http://localhost:8000/ を開く
```

### 入力の流れ

1. **お客様・住まい**：地域（日射データ地点）、家族人数、生活スタイル、延床面積（坪）、階数、断熱性能
   - 電気の検針票があれば、年間使用量の実績で補正できます
2. **屋根**：形状（切妻・片流れ・寄棟・陸屋根）、向き、勾配 → 屋根面と載る枚数を自動計算
   - 図面がある場合は、面ごとの「最大枚数」を実際の割付けで上書きしてください
3. **パネル**：メーカー・機種（手入力も可）、計算方式（JPEA / JIS C 8907）
4. **空調**：エアコンの部屋・畳数・台数・運転時間。**ペットがいる場合はチェック**で24時間運転に
5. **給湯・調理・家事家電**：エコキュート（昼間沸き上げも可）、IH、食洗機、乾燥機、床暖房など
6. **EV・V2H・蓄電池**：車種クラス、走行距離、日中に車が家にある日数、V2H、蓄電池容量
7. **停電への備え**：停電時に使いたい機器、「停電対策を優先」
8. **料金・売電・費用**：提案の目的（経済性 / 自給 / 屋根いっぱい）、電気料金、FIT単価、見積単価

入力するとすぐ右側の結果が更新されます。

### 結果の見方

| 表示 | 内容 |
|---|---|
| おすすめの容量 | 選んだ目的での推奨kW・枚数と主要指標（発電量・自給率・回収年数・累計収支） |
| 根拠（4つの基準） | 収支最大・ネットゼロ・屋根上限・停電対策ラインの各容量 |
| 累計収支カーブ | 容量を増やしたときの20年収支・自給率・自家消費率の変化 |
| 根拠の説明文 | お客様にそのまま説明できる文章（消費量・日射・屋根・経済性・自給・停電） |
| 月別グラフ / 1日の流れ | 季節ごとの過不足、晴れの日の発電・消費・買電の時間変化 |
| 電気の使い道 | 機器ごとの消費量と全国平均との比較 |
| 容量別の比較表 | 容量ごとの発電量・自家消費率・自給率・年間メリット・回収年数・累計収支 |

### 保存・提案書

- **保存 / 開く**：お客様ごとにこのブラウザ内（localStorage）に保存
- **書出 / 読込**：JSON ファイルでのバックアップ・別PCへの移行
- **提案書を印刷**：入力欄を除いた提案書レイアウトで印刷（「PDFに保存」で PDF 化）

## 前提値の変更

- 機器の消費量・パネル機種・単価などの既定値：`js/data/catalog.js`
  - パネル機種は代表値です。**提案前に必ず最新カタログの公称最大出力・外形寸法・温度係数を確認**してください
- 気象データの再取得（通常は不要）：

```bash
cd tools
python3 fetch_jma.py      # 気象庁 平年値（日射量・気温）を取得 → jma_normals.json
python3 fetch_pvgis.py    # PVGIS の傾斜面日射量を取得（約3,000リクエスト・数分）→ pvgis_cache.json
python3 build_climate.py  # js/data/climate.js を生成
```

## テスト

```bash
npm test   # または node --test tests/*.test.js
```

発電量の水準（東京・南30°で1kWあたり1,050〜1,300kWh）、方位・地域差、エネルギー収支の整合、
蓄電池/V2H の効果、FIT区分、推奨ロジックなどを検証しています。

## ファイル構成

```
index.html              画面
css/style.css           スタイル（印刷用レイアウトを含む）
js/engine.js            計算エンジン（発電・消費・需給・経済性・推奨）
js/app.js               画面制御
js/charts.js            グラフ描画（SVG、外部ライブラリなし）
js/data/climate.js      気象データ（自動生成）
js/data/catalog.js      機器・パネル・制度の前提値
docs/根拠と計算方法.md   計算方法と出典
tools/                  気象データの取得・生成スクリプト
tests/                  テスト
```

## 注意

本ツールの結果は推計です。実際の発電量・電気代は、天候、影、積雪、出力制御、使い方、機器の性能によって変わります。
最終的な提案では、メーカーのシミュレーションや現地調査の結果と合わせてご確認ください。
