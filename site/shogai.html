障害福祉の書類ツール

就労継続支援・就労移行支援・生活介護・グループホーム

個別支援計画・モニタリング・日々の支援記録から、欠席時対応、個別支援会議、委員会や研修の記録まで。希望や様子を選ぶだけで、記載事項のそろった下書きを作れます。

よく探される書類

新着 個別支援計画の下書き就労B・A・移行・生活介護・GHに対応。希望と課題を選ぶと、目標と支援内容の下書きに。使ってみる → 新着 児童障害アセスメントシートの下書き面談で聞いた希望と、領域ごとの「できていること」「支援が必要なこと」を選ぶと、課題の整理（ニーズ）まで入ったアセスメントシートに。使ってみる → 新着 工賃（賃金）向上計画の下書き前年度の平均工賃と目標を入れて、課題と取り組みを選ぶと、伸び率の表と3年間のスケジュールが入った工賃向上計画に。使ってみる → 新着 共通虐待防止のセルフチェック表身体的・心理的・性的・ネグレクト・経済的の5つと「不適切なケアのグレーゾーン」を31項目でふり返り。介護・障害・児童で言い回しが変わり、類型ごとの集計と気になる項目の一覧に。使ってみる → 新着 支援記録（日々の記録）の文例就労B・A・移行・生活介護・GH。通所の状況・作業の様子・体調・本人の言葉・支援内容を選ぶと、日々の記録の文章に。使ってみる → 児童障害モニタリング記録の下書き目標ごとに達成の度合いと様子を選ぶと、評価・今後の方針・計画変更の要否まで入ったモニタリング記録に。使ってみる → 児童障害欠席時対応の記録欠席時対応加算の記録に。連絡の日時・欠席の理由・相談援助の内容を選ぶと、そのまま使える記録文に。使ってみる → 児童障害個別支援会議の記録計画の作成・見直しの会議の記録に。出席者・検討した内容・本人の意見・決まったことを選んで、議事録の形に。使ってみる → 新着 共通ヒヤリハット報告書の下書き「転倒しそうになった」「薬を配り間違えかけた」などを選ぶと、要因と対策まで入った報告書に。使ってみる → 障害介護申し送りメモの下書き体調・食事・排泄・睡眠・服薬・受診・家族連絡を選ぶと、次の勤務に伝わる申し送りの形に。使ってみる → 新着 障害介護身体拘束の3要件の検討記録代わりの方法から順に、切迫性・非代替性・一時性を確認。満たさない要件があれば「行わない」結論に。説明・経過観察の欄つき。使ってみる → 障害介護ご家族への近況報告（お便り）季節のあいさつ・生活の様子・行事・お願いを選ぶと、ご家族に送る近況報告の文章に。使ってみる → 新着 共通委員会の議事録の下書き虐待防止・身体拘束適正化・感染症対策・事故防止・業務継続（BCP）。議題を選ぶと、検討内容と決定事項まで入った議事録に。使ってみる → 新着 共通研修・訓練の年間計画表サービスの種類と開始月を選ぶと、虐待防止・身体拘束・感染症・BCP・災害などの研修と訓練を12か月に割り振った計画表に。使ってみる → 共通研修の実施記録研修のテーマを選ぶと、目的・内容・確認テスト・振り返りまで入った研修記録に。虐待防止・身体拘束・感染症など。使ってみる → 共通事故・ヒヤリハット報告の下書き国の標準様式の項目で、原因分析と再発防止策まで。使ってみる →
