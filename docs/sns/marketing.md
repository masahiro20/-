# インスタで「使ってみよう！」と思ってもらうための作り方

## 見る人の状況

- 見ているのは、休憩中・帰りの電車・寝る前の介護士さん、支援員さん、児発管・サビ管さん。疲れていて、指はすぐ次の動画へ動く。
- 「新しいツール」には慎重。ログインが面倒、個人情報が心配、職場で使っていいか分からない。
- でも「記録が終わらない」「連絡帳が同じ文になる」「運営指導が怖い」は、毎日の本音。

→ **1秒目で「それ、わたしのことだ」と思わせ、10秒以内に「これなら明日すぐ使える」を見せる。**

## 動画の型（全リール共通）

| 時間 | やること | ねらい |
|---|---|---|
| 0〜2秒 | 現場の「あるある」を大きな文字と声で（例：記録に「不穏」って書いたこと、ある？） | 指を止める。共感 |
| 2〜4秒 | ひとことで解決を示す（タップするだけで） | 「自分にもできそう」 |
| 4〜10秒 | 本物の画面で、3〜5回タップ（タップ音つき） | 操作の簡単さを目で見せる |
| 10〜13秒 | 完成した書類＋「完成！」のマークと効果音 | ごほうびの瞬間 |
| 最後 | 保存してね／ほしい書類はコメントで／プロフィールのリンク | 保存・コメントは、おすすめに載りやすくなる |

- 長さは15〜25秒。最後まで見てもらえる長さにする。
- 声は「隣の席の先輩」の話し言葉。共感の一言は落ち着いた声、紹介は明るい声。
- 「無料・登録なし・入力は送信しない」を必ず見せる（不安を先に消す）。

## 3つのシリーズ

1. **あるある解決**（#1〜#5）：1本1ツール。悩みの言葉で始める。
2. **現場の1日**（#6〜#8）：夕方の記録、お迎え前の連絡帳、運営指導の通知。イラストの場面で「自分の職場」を思い浮かべてもらう。
3. **リクエストにお応えしました**（これから）：コメントや意見箱でもらった「ほしい書類」を作ったら、その人の言葉を紹介して新しいリールに。続けて見てもらえる理由になる。

## 音について

- 声は Style-Bert-VITS2 の「小春音アミ」モデル（あみたろの声素材工房の声を元にしたモデル）。商用で使えるが、**キャプションにクレジットを必ず入れる**。
- BGMは自作の明るい曲（ハ長調・118BPM、ピチカート・グロッケン・手拍子）。楽器の音はMITライセンスの音源。
- 動画は2種類：
  - `final`（声＋効果音＋BGM）…そのまま投稿。
  - `final-voice`（声＋効果音だけ）…インスタで流行りの音源を小さめに足す用。流行りの音源は、おすすめに載りやすくなることがある。アカウントは「クリエイター」にしておく（ビジネスアカウントだと使える音源が限られる）。

## もっと伸ばすために（あなたにしかできないこと）

- **本物の手元**：スマホで実際にタップしているところを、手元だけ撮った動画は、いちばん信頼される。撮影は「机の上でスマホを持って、ツールをタップする」だけ（顔は出さない）。撮った動画をもらえれば、字幕と声をこちらで付けます。
- **本人の声**：あなたの声で読んだナレーションは、合成音声より親しみがわく。台本は `docs/sns/instagram-reels.md` にあります。スマホで録った音声をもらえれば、差し替えます。
- **最初の100人**：知り合いの福祉職の人に、DMやLINEで「使ってみて、感想ちょうだい」と送る。最初のコメントと保存が、次の人に届くきっかけになる。

## 数字の見方（週1回）

| 見る数字 | 目安 | 低いときに直すところ |
|---|---|---|
| 3秒後も見ている人の割合 | 60%以上 | 最初の一言（もっと具体的な「あるある」に） |
| 最後まで見た人の割合 | 30%以上 | 長さ（短く）・操作の場面（速く） |
| 保存数 ÷ 再生数 | 1%以上 | 「完成」の見せ方・保存の呼びかけ |
| プロフィールへのアクセス → リンクのタップ | ふえているか | プロフィール文・リンク先（start.html） |
