# ふくしのおたすけ帳：運営プラン

介護・障害福祉・児童支援の現場で働く人のための、**無料の書類ツール集**。
「あのサイト使うと計画書すぐできるよ」と、職場の中で口コミで広がることを目指す。

---

## 1. いま使えるツール（計画書・記録・報告・会議・研修）

| 業種 | ツール | ページ |
|---|---|---|
| 児童支援（放デイ・児発） | 個別支援計画の下書き（5領域・国の参考様式どおり） | `jido-keikaku.html` |
| | 連絡帳の文例メーカー（毎日使える・保護者向け） | `renrakucho.html` |
| | 支援プログラムの下書き（手引きの①〜⑫、ホームページ掲載用HTML） | `program.html` |
| | 個別支援計画の文例集（31課題）・書き方・運営指導前チェックリスト・白紙様式 | `bunrei/` ほか |
| 障害福祉（就労B・A・移行・生活介護・GH） | 個別支援計画の下書き（基準の記載事項どおり、本人の役割つき） | `shogai-keikaku.html` |
| | 支援記録（日々の記録）の文例 | `shien-kiroku.html` |
| 障害福祉・児童 | モニタリング記録／欠席時対応の記録（加算の要件チェックつき）／個別支援会議の記録 | `monitoring.html` `kesseki.html` `kaigi.html` |
| 介護 | 事故報告書（厚労省の標準様式） | `jiko.html` |
| | 介護記録（ケース記録）の文例（主観語のチェックつき） | `kaigo-kiroku.html` |
| 介護・障害福祉 | 申し送りメモ／ご家族への近況報告（お便り） | `moushiokuri.html` `kinkyo.html` |
| 3業種すべて | ヒヤリハット報告書／委員会の議事録（虐待防止・身体拘束・感染症・事故防止・BCP）／研修・訓練の年間計画表（サービス種別ごとの回数）／研修の実施記録（○×問題つき） | `hiyari.html` `iinkai.html` `kenshu-keikaku.html` `kenshu-kiroku.html` |
| 全体 | 意見箱（ほしい書類・要望・不具合） | `iken.html` |

新しい書類テンプレートは、共通のしくみ（`site/assets/formdoc.js`）で動く。1件の追加は「`data/templates.mjs` に説明を1件」＋「`site/assets/tpl/<id>.js`」だけ。

すべてのツールに共通する機能：
- 選ぶだけで、国の様式どおりの下書き
- 下書きの文章はその場で書き換え可能
- コピーして事業所の様式やソフトに貼る
- 「AIで文章を整える」：個人情報を含まない依頼文をコピーし、ChatGPT・Claude・Gemini に貼って整えてもらう（AIの利用料はかからない）
- LINE・X・URLコピーの共有ボタン（口コミの入口）
- 「リンクで共有」：選んだ課題・要因だけをURLにして同僚に送れる（入力した文章は含まない）
- 職場に貼れる紹介チラシ（`flyer.html`、QRコードは表示中のサイトのURLから自動で作る）
- 入力内容はブラウザの外に送らない

## 2. 収益：アフィリエイト（PR枠）

`data/config.mjs` の `affiliates` に、ASP で提携した広告のリンクを入れると、その業種のページにだけ「PR」表示つきで出る。リンクが空の枠は表示されない。

| 枠 | 出すページ | 探す案件の例 |
|---|---|---|
| 介護職の求人 | 介護 | 介護職の転職・求人サイトの会員登録（A8.net・アクセストレードなどで扱いあり） |
| 児発管・サビ管・支援員の求人 | 児童支援・障害福祉 | 障害福祉・児童福祉に特化した求人サイト |
| 資格講座の資料請求 | 介護・障害福祉 | 実務者研修・初任者研修の講座を一括で資料請求できるサービス |
| 請求・記録ソフト | 全ページ | 介護・障害福祉の請求ソフトの資料請求 |

**始め方（👤 あなたの作業）**
1. A8.net・アクセストレード・もしもアフィリエイトなどに、サイトのURLを登録して会員になる（サイト公開後に審査がある）。
2. 「介護 求人」「保育 求人」「障害福祉 求人」「資格 資料請求」などで案件を探し、提携を申し込む。
3. 提携できた案件の広告リンクを `data/config.mjs` の `affiliates` の `url` に貼り、`node scripts/build.mjs` を実行する（こちらでもできます）。

**守ること**
- 広告には必ず「PR」を表示する（景品表示法のステマ規制）。いまの枠は自動で表示される。
- ツールの結果の中に広告を混ぜない（信頼を失うと口コミが止まる）。
- 求人の広告は「転職をあおる」言い方にしない。

## 3. 口コミで広げる仕掛け

| 仕掛け | 内容 |
|---|---|
| 共有ボタン | 各ツールの下に「同じ職場の方にも、教えてあげてください」＋LINE・X・URLコピー |
| 業種ごとの入口 | 「児童支援」「障害福祉」「介護」のページをそのまま送れば、自分の職場に関係するツールだけが並ぶ |
| 検索の入口 | 文例ページ・書き方ページ（「〇〇 個別支援計画 文例」「事故報告書 転倒 例文」などで来てもらう） |
| SNS | `docs/sales/sns-posts.csv` の投稿文（児童支援）。介護・障害福祉の分も追加予定 |

## 4. 次に作るツール

意見箱に届いた声を優先する。いまの候補（各業種ページに「準備中」として表示中）：

| 業種 | ツール | 理由 |
|---|---|---|
| 児童 | おたより（月1回のお知らせ）の文例 | 毎月書く |
| 児童 | 安全計画（送迎・置き去り防止）の下書き | 令和5年度から義務 |
| 障害 | アセスメントシートの下書き | 計画の前に必ず作る |
| 障害 | 工賃（賃金）向上計画の下書き | 就労Bで毎年作る |
| 介護 | ヒヤリハットの月別集計表 | 事故防止委員会の資料 |
| 介護 | 看取り（ターミナルケア）の記録の文例 | 加算の記録で負担が大きい |

競合と口コミの見立ては `docs/competition.md` を参照。
