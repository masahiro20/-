# お問い合わせ 返信テンプレート

方針：
- 返信は **2営業日以内**。
- 最初の一文でお礼を伝え、結論を先に書く。
- 個別の計画内容が運営指導で認められるかどうかなど、制度の解釈についての個別相談は受けない。自治体（指定権者）への確認を案内する。
- 文例追加のリクエストは `docs/sales/requests.md` に書き留め、月1回まとめて反映する。反映したら、リクエストをくれた人にお知らせする。

---

## 1. 購入前の質問（動作環境）
```
お問い合わせありがとうございます。

Excel 2016以降（Windows／Mac）、Microsoft 365 でお使いいただけます。
Googleスプレッドシートや LibreOffice でも、課題のプルダウンと文例の自動入力が動きます
（フォントやセルの高さが少し変わることがあります）。

無料の白紙様式で、お使いの環境で開けるか先にお試しいただくこともできます。
（サイトのURL）/download.html

ほかにも気になる点があれば、お気軽にお知らせください。
```

## 2. ダウンロードできない
```
お問い合わせありがとうございます。ご不便をおかけしています。

BOOTHにログインし、「購入履歴」から該当のご注文を開くと、ダウンロードボタンが表示されます。
スマートフォンではZIPファイルを開けないことがあるため、パソコンでのダウンロードをおすすめしています。

それでもダウンロードできない場合は、ご注文番号をお知らせください。こちらで確認いたします。
```

## 3. Excel が開けない・文例が入らない
```
お問い合わせありがとうございます。

以下をお試しいただけますか。
1. ZIPファイルを「すべて展開」してから、Excelファイルを開いてください（ZIPの中から直接開くと保存できません）。
2. 画面上部に「保護ビュー」「編集を有効にする」と表示されたら、「編集を有効にする」を押してください。
3. 課題は「計画書（文例入り）」シートの、左側の黄色いセルで選びます。

それでも解決しない場合は、お使いのExcelのバージョン（例：Microsoft 365、Excel 2019、Mac版など）と、
画面のスクリーンショットをお送りください。
```

## 4. 領収書がほしい
```
お問い合わせありがとうございます。

領収書をPDFでお送りします。以下をお知らせください。
・ご注文番号
・宛名（事業所名・法人名）
・但し書きの指定があれば（例：個別支援計画様式代として）
```
> 領収書は、日付・宛名・金額・但し書き・発行者名を入れたPDFで送る。インボイス登録をしていない場合、登録番号は書かない。

## 5. 請求書払い・複数の事業所でまとめて買いたい
```
お問い合わせありがとうございます。

現在はBOOTHでのお支払いのみ承っております。
同じ法人の複数事業所でお使いいただく場合は、1つのご購入で各事業所に共有していただけます（利用規約の範囲内です）。
```

## 6. 自治体の様式と違う・項目を追加したい
```
お問い合わせありがとうございます。

Excelなので、項目名・列幅・事業所名などは自由に変更していただけます。
「計画書（文例入り）」シートの数式が入っているセル（白いセル）の位置を動かすと、文例が入らなくなることがあります。
列や行を追加するときは、「計画書（白紙）」シートを編集されるのが安全です。

ご希望の様式があれば、今後の改善の参考にさせていただきます。
```

## 7. 「この計画で運営指導は大丈夫？」（個別相談）
```
お問い合わせありがとうございます。

申し訳ありませんが、個別の計画内容が運営指導で認められるかどうかについては、お答えしておりません。
記載方法の細かな求めは自治体によって異なるため、指定権者（自治体の担当課）へご確認いただけますと確実です。

国の「記載のポイント」に沿った書き方の目安は、こちらにまとめています。
（サイトのURL）/kakikata.html
```

## 8. 文例を追加してほしい
```
リクエストをありがとうございます！

「○○」の文例、次回のアップデートで追加を検討します。
追加したら、購入された方はBOOTHの購入履歴から最新版をダウンロードいただけます。
追加の際には、こちらからもお知らせしますね。
```

## 9. 返金してほしい
```
お問い合わせありがとうございます。

大変申し訳ありませんが、デジタル商品の性質上、ご購入後の返金はお受けしておりません
（特定商取引法に基づく表記・利用規約に記載しております）。

ファイルが開けない、文例が入らないなどの不具合でしたら、解決まで対応いたしますので、
状況をお知らせいただけますか。
```

## 10. 不具合の報告
```
ご報告ありがとうございます。とても助かります。

確認のため、以下を教えていただけますか。
・お使いのソフト（Excel／Googleスプレッドシートなど）とバージョン
・どのシートの、どのセルで起きたか
・可能であれば画面のスクリーンショット

修正版ができしだい、BOOTHで差し替えてお知らせします。
```
