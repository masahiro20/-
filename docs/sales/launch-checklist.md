# 販売開始までのチェックリスト

上から順に進めれば、販売を始められます。**あなたの操作が必要なもの**には 👤 をつけています。所要時間の目安は、合計2〜3時間です。

| もの | 場所 | 状態 |
|---|---|---|
| サイト一式（46ページ） | `site/` | 完成。公開するだけ |

## 1. 👤 ドメインを決める（15分）

- 例：`kobetsu-bunrei.jp`、`bunreicho.com` など。短く、読みやすいもの。
- お名前.com、Cloudflare Registrar などで取得（年1,500〜3,000円前後）。
- 急がない場合は、先に Cloudflare Pages の無料URL（`○○.pages.dev`）で公開してもかまいません。

## 2. 👤 BOOTH のショップを開く（30分）

1. [BOOTH](https://booth.pm/) に pixiv アカウントでログインし、ショップを作る。
2. 振込先の口座を登録する。
3. ショップの設定で、特定商取引法に関する情報を案内に沿って登録する。
4. 「商品を登録」→「ダウンロード商品」。
5. `docs/sales/booth-listing.md` の内容を貼り付け、画像5枚と ZIP をアップロード。
6. まずは「非公開」で保存し、自分で表示を確認してから公開する。
7. 公開した商品ページのURLをメモする（例：`https://○○.booth.pm/items/1234567`）。

## 3. 👤 問い合わせ窓口を作る（15分）

- 購入者対応用のメールアドレスを用意する（例：Gmail で専用アドレスを作る）。
- あわせて問い合わせフォームも使う場合は、Googleフォームで次の項目を作る。
  - お名前（必須）／メールアドレス（必須）
  - お問い合わせの種類（必須・選択式）：購入前の質問／ダウンロード・ファイルについて／領収書／文例のリクエスト／その他
  - ご注文番号（任意）
  - お問い合わせ内容（必須・段落）
  - フォームの設定で「回答のコピーを回答者に送信」をオンにすると、自動返信の代わりになる。

## 4. 👤→🤖 設定ファイルを埋める（5分）

`data/config.mjs` の TODO を埋める。分からなければ値を教えてもらえれば、こちらで入れます。

| 項目 | 入れる値 |
|---|---|
| `siteUrl` | 公開するURL（例：`https://bunreicho.com`） |
| `productUrl` | BOOTH の商品ページURL |
| `supportEmail` | 購入者対応用のメールアドレス |
| `contactUrl` | Googleフォームの URL（使わない場合は空のまま） |
| `sellerName` | 販売事業者名（個人の場合は氏名） |
| `sellerAddress`・`sellerPhone` | 個人で公開したくない場合は、今の「請求があった場合には遅滞なく開示いたします。」のままでOK |
| `gaId` | Google アナリティクスの測定ID（任意） |

埋めたら、次を実行する（こちらでも実行できます）。

```sh
node scripts/build.mjs          # サイトを作り直す
./products/build.sh             # 商品（ZIP）を作り直す（連絡先が「はじめに」に入る）
node scripts/sns-posts.mjs      # SNS投稿文のURLを本番のものにする
```

## 5. 👤 サイトを公開する（20分）

**Cloudflare Pages（無料）**
1. Cloudflare にログイン →「Workers & Pages」→「作成」→「Pages」→「Git に接続」。
2. このリポジトリを選ぶ。
3. ビルドの設定：
   - フレームワーク：なし
   - ビルドコマンド：`node scripts/build.mjs`
   - ビルド出力ディレクトリ：`site`
4. 「保存してデプロイ」。数分で `○○.pages.dev` で公開される。
5. 独自ドメインを使う場合は「カスタムドメイン」から追加。

## 6. 👤 検索エンジンに知らせる（10分）

1. [Google Search Console](https://search.google.com/search-console) にサイトを登録。
2. 「サイトマップ」に `sitemap.xml` を送信。
3. （任意）Bing Webmaster Tools にも同じように登録。

## 7. 公開前の最終確認

- [ ] サイトのトップ・販売ページ・無料様式ページがスマホで崩れずに見える
- [ ] 販売ページの購入ボタンが BOOTH の商品ページに飛ぶ
- [ ] 無料様式がダウンロードできる
- [ ] 特定商取引法に基づく表記に「【公開前に記入】」が残っていない
- [ ] BOOTH で自分で購入テスト（またはショップのプレビューでダウンロードを確認）
- [ ] リポジトリを非公開にした

## 8. 公開後の運用（週2〜3時間）

| 頻度 | やること |
|---|---|
| 毎日（自動） | SNS に `docs/sales/sns-posts.csv` の投稿を1本ずつ予約投稿（X の予約投稿機能や、予約投稿ツールを使う） |
| 届いたら | 問い合わせに `docs/sales/support-templates.md` で返信（2営業日以内） |
| 週1回 | Search Console で、どの検索語で来ているかを確認し、よく見られている文例ページを確認 |
| 月1回 | 文例のリクエストをまとめて追加 → `node scripts/build.mjs` と `./products/build.sh` → BOOTH の ZIP を差し替え |
| 制度改定時 | 国・自治体の通知を確認して文例を直す |

## 9. お金まわり

- BOOTH の手数料：1件あたり「価格の5.6%＋45円」。3,980円なら手取りは約3,710円。
- 会社員の副業で、年間の所得（売上−経費）が20万円を超えたら確定申告が必要。ドメイン代などは経費になる。
- 事業所から「インボイス対応の領収書がほしい」と言われることがある。インボイス登録をするかどうかは、売上の見込みを見て判断する（登録しなくても販売はできる）。
