# 根拠と計算方法

このツールが「何kWがベストか」を出すまでの考え方・計算式・数値の出典をまとめたものです。
お客様から「その数字の根拠は？」と聞かれたときに、そのまま説明に使えるように書いています。

---

## 1. 全体の流れ

```
 お客様の条件 ──┬─▶ ① 年間・時間別の「使う電気」（消費量モデル）
               │
 地域・屋根 ────┼─▶ ② 年間・時間別の「つくる電気」（発電量モデル）
               │
 EV・蓄電池 ────┴─▶ ③ 365日×24時間の需給シミュレーション
                       （自家消費・売電・買電・蓄電池/V2H の充放電）
                              │
                              ▼
               ④ パネルを1枚ずつ増やして全ケースの20年収支を計算
                              │
                              ▼
               ⑤ 4つの基準から推奨容量を決定
                  ・経済性（累計収支が最大）
                  ・ネットゼロ（年間発電 ≧ 年間消費）
                  ・屋根に載る上限
                  ・停電対策ライン
```

メーカーのシミュレーション（例：シャープ「発電Dr」）も「地域・屋根・家族構成・生活スタイル・料金プラン」から
発電量と収支を出す構成です。本ツールはそれに加えて、**空調の台数・運転時間（ペットの24時間空調など）、
断熱等級、EV/V2H、停電時に必要な電力**まで積み上げ、**容量を変えながら比較して「ベストな容量」を選ぶ**点が特徴です。

## 2. 発電量（つくる電気）

### 2-1. 計算式

太陽光発電協会（JPEA）「表示ガイドライン（2026年度）」の推定発電量の計算式を使います。
メーカーのカタログに載っている「年間推定発電量」と同じ考え方です。

```
月間発電量[kWh] = 容量[kW] × 月間傾斜面日射量[kWh/㎡] × Kh × Kpcs × Kj
年間発電量      = 12か月の合計
```

| 記号 | 意味 | 既定値 |
|---|---|---|
| Kh | 太陽電池の補正係数（主に温度による出力低下） | JPEA参考値：1〜3月・12月 0.90 ／ 4〜5月・10〜11月 0.85 ／ 6〜9月 0.80 |
| Kpcs | パワーコンディショナの変換効率 | 96%（各社の定格効率。入力で変更可） |
| Kj | その他の損失（汚れ・配線・回路） | 95%（JPEAは「各社で根拠を持つこと」としている） |

**計算方式「JIS C 8907」を選んだ場合**は、Kh をパネルの温度係数から月ごとに計算します。

```
Kh = 0.97（日射量年変動） × 0.95（経時変化・汚れ） × {1 + 温度係数 × (月平均気温 + ΔT − 25)}
ΔT = 21.5℃（屋根置き形）／ 18.4℃（陸屋根の架台設置形）
```

温度係数が小さいパネル（例：ヘテロ接合 −0.26%/℃）ほど夏の発電量が落ちにくい、といったメーカー間の違いを説明できます。

### 2-2. 日射量データ

| データ | 出典 | 使い方 |
|---|---|---|
| 水平面の月平均全天日射量・月平均気温 | **気象庁 平年値（1991〜2020年）** 全国63地点 | 地域の日射量のベース |
| 傾斜面／水平面の日射量比（月別・8方位×7勾配） | **PVGIS v5.2**（欧州委員会 共同研究センター JRC、ERA5 再解析 2005〜2020年） | 屋根の向き・勾配への換算 |

- 気象庁の日射観測がない地点（水戸・熊谷・千葉・横浜・金沢・岐阜・津・京都・神戸・和歌山・鳥取・岡山・山口・徳島など17地点）は、
  PVGIS の水平面日射量を「近くの気象庁観測点2地点での 実測値／PVGIS 比」で補正した**推計値**です（画面に「推計」と表示）。
- JPEA ガイドラインは NEDO の MONSOLA-20 の使用を推奨しています。MONSOLA は Web 閲覧のみでデータを機械的に取り込めないため、
  本ツールは**同じく実測に基づく気象庁平年値**を使っています。南向き30°の年間傾斜面日射量は
  東京 約1,500 kWh/㎡、名古屋 約1,650、札幌 約1,480、那覇 約1,530 kWh/㎡ と、MONSOLA の値と概ね数％以内で一致します。
- 参考：東京・南向き30°・JPEA方式で 1kWあたり **約1,160 kWh/年**。一般に言われる「1kWあたり年間1,000〜1,300kWh」の範囲です。

データの再取得・再生成は `tools/` のスクリプトで行えます（README参照）。

### 2-3. 時間ごとの発電

- 月の発電量を、その月の日の出〜日の入りと屋根の方位（東向きは午前、西向きは午後にピーク）に合わせて時間配分します。
- 天候のばらつきを再現するため、各月に**晴れ・曇り・雨の日**（日射の比 1.45 : 0.75 : 0.25、出現率 45% / 35% / 20%）を混ぜます。
  **月の合計は平年値と一致**するように補正しているので、年間発電量は 2-1 の式の結果と同じです。
- 晴れの日だけ・平均的な日だけで計算すると、自家消費率や蓄電池の効果を過大評価しやすいため、この方式にしています。

### 2-4. パワコン容量（過積載）

- パネル容量が 10kW 未満なら、パワコン容量＝パネル容量として扱います。
- パネル容量が 10kW 以上になる場合、既定では**パワコンを 9.9kW**として計算します（住宅用FIT区分を維持する「過積載」）。
  パワコン出力を超える分はピークカットとして差し引きます。
- FIT の区分は「パネル合計とパワコン出力の小さい方」で判定します。10kW以上（事業用・屋根設置）は自家消費率30%以上の要件があるため、下回ると警告を出します。

## 3. 消費量（使う電気）

機器ごとに年間の消費電力量を積み上げ、月ごと・時間ごとに配分します。

| 項目 | 計算方法 | 根拠 |
|---|---|---|
| 照明・冷蔵庫・家電・待機電力 | 人数別代表値 1人1,700 〜 6人3,600 kWh/年＋延床補正 | 環境省「家庭部門のCO2排出実態統計調査（R5）」戸建の照明・家電等 約3,300kWh/年 |
| 24時間換気 | 200 kWh/年 | 換気扇 約20〜30W×24時間 |
| 在宅ワーク | 250 kWh/人・年（9〜18時） | PC・モニター・照明の追加分 |
| 個別エアコン | JIS C 9612 期間消費電力量（6畳 700 〜 26畳 2,800kWh）× 運転時間係数 × 断熱係数 × 地域の気温補正 | 下記 3-1 |
| 全館空調 | 30 kWh/㎡・年（断熱等級4・東京相当）× 断熱係数 × 気温補正＋送風 2kWh/㎡ | 実測事例（年1,500〜3,000kWh/30〜35坪） |
| 床暖房 | 温水式(HP) 35 / 電気ヒーター式 90 kWh/㎡・年 × 気温・断熱補正 | 代表値 |
| エコキュート | (500 + 250×人数) kWh/年 × 地域（水温）補正 | 4人で約1,500kWh/年（1日約4kWh） |
| 電気温水器 | エコキュートの3倍 | COP 約3 の差 |
| ハイブリッド給湯 | エコキュートの0.6倍 | 代表値 |
| IH | 200 + 120×人数 kWh/年 | 代表値 |
| 食洗機 | 0.8 kWh/回 × 365回 | 代表値 |
| 衣類乾燥 | HP式 0.9 / ヒーター式 2.5 kWh/回 | 代表値 |
| 浴室乾燥 | 1.3 kWh/回 | 代表値 |
| EV | 年間走行距離 ÷ 電費 × 自宅充電割合 ÷ 充電効率0.9 | 下記 3-3 |

### 3-1. エアコン（ペットの24時間空調を含む）

- **基準**：JIS C 9612（2013）の期間消費電力量。東京・木造住宅で、6時〜24時（18時間）運転したときの年間消費電力量で、カタログに載っている値です。
- **運転時間係数**：在室時のみ（約8時間）0.5 ／ 日中＋夜（約14時間）0.8 ／ 18時間 1.0 ／ **24時間つけっぱなし 1.25**
  （夜間は外気との温度差が小さいため、時間に比例するほどは増えない）
- **断熱係数**（JIS想定の住宅＝1.0）：等級3以下 1.0 ／ 等級4 0.8 ／ 等級5(ZEH) 0.7 ／ 等級6(G2) 0.55 ／ 等級7(G3) 0.42
- **地域補正**：月平均気温から冷房度日（20℃超）・暖房度日（15℃未満）を計算し、東京との比で冷房分（27%）・暖房分（73%）をそれぞれ補正。
  月ごとの配分も度日に比例させています（夏・冬に多く、春秋は少ない）。
- 例：東京・ZEH水準・18畳用を24時間運転 → 約1,660kWh/年（「日中＋夜」運転より約600kWh多い）。

### 3-2. 生活スタイル

- 「共働き等で平日日中不在」なら平日の日中の消費が少なく、夕方〜夜に集中します（自家消費率が下がる）。
- 「日中も在宅」「在宅ワーク」では日中の消費が増え、太陽光の電気を直接使える割合が上がります。
- 土日は全員在宅のパターンで計算します。

### 3-3. EV・V2H

- 毎日18時に帰宅し、その日の走行分を電池から消費したとみなします。
- 車が家にある時間（夜間＋「日中に車が家にある日」）は、**太陽光の余剰で充電**できます（余剰充電ON時）。
- 夜間（料金プランの夜間時間帯）に、翌日の走行分＋残量下限まで系統から充電します。
- **V2H** がある場合、車が家にある間は「残量下限＋翌日の走行分」を超える電気を家に給電します
  （夜間に買った電気をそのまま家に戻す無駄な往復はしません）。

### 3-4. 実績による補正

電気の検針票から年間使用量がわかる場合は、モデルの値（EVを除く）を実績に合わせて比例補正できます。
ただし新築・建て替えで設備が変わる場合（ガス→オール電化、断熱性能アップ等）は補正しない方が正確です。

### 3-5. 統計との比較（説得材料）

環境省「令和5年度 家庭部門のCO2排出実態統計調査」の世帯人数別CO2排出量（電気）を、全国平均の比
（1.67 t-CO2 ↔ 3,911 kWh）で電力量に換算した参考値を表示します。

| 世帯人数 | 1人 | 2人 | 3人 | 4人 | 5人 | 6人以上 |
|---|---|---|---|---|---|---|
| 年間電力消費量（参考） | 約2,400 | 約3,900 | 約5,100 | 約5,800 | 約6,600 | 約8,900 kWh |

※ガス併用世帯を含む平均です。オール電化＋24時間空調＋EV の家庭は平均の1.5〜2倍になるのが普通で、
「平均的な家庭向けの4〜5kWでは足りない」ことを説明する材料になります。

## 4. 需給シミュレーション（365日×24時間）

1時間ごとに次の順で電気の流れを計算します。

```
発電 ＞ 消費 のとき（余剰）： ① 家で使う → ② 蓄電池に充電 → ③ EVに充電（在宅時） → ④ 売電
発電 ＜ 消費 のとき（不足）： ① 太陽光 → ② 蓄電池から放電 → ③ V2HでEVから給電 → ④ 買電
夜間                     ： EVの翌日走行分を系統から充電
```

- 蓄電池：実効容量・出力・往復効率（既定90%）を考慮。
- 結果として、自家消費率（発電のうち家で使った割合）、自給率（消費のうち買わずに済んだ割合）、買電量・売電量が出ます。

## 5. 経済性

```
年間メリット = 電気代削減額（太陽光なしの電気代 − 太陽光ありの電気代） + 売電収入
累計収支(N年) = Σ 年間メリット × 劣化(0.5%/年) × 電気代上昇(1%/年) − 導入費
```

| 項目 | 既定値 | 出典 |
|---|---|---|
| 買電単価 | 31円/kWh（一律）。時間帯別も選択可 | 全国家庭電気製品公正取引協議会 電力料金目安単価（税込） |
| 売電（10kW未満） | 1〜4年目 24円 → 5〜10年目 8.3円 | 経済産業省 FIT「初期投資支援スキーム」（2025年10月〜、2026年度も同額） |
| 売電（10kW以上・屋根） | 1〜5年目 19円 → 6〜20年目 8.3円 | 同上 |
| 卒FIT後 | 8円/kWh | 想定（大手電力の買取メニュー水準） |
| 導入費 | 30万円 ＋ 22万円/kW | 調達価格等算定委員会：2025年 住宅用新築平均 28.9万円/kW（既築 30.1万円/kW）を固定費＋比例費に分解 |

- 導入費を「固定費＋1kWあたり」に分けているのは、パネルを1枚増やすときの**追加費用（限界費用）**を正しく扱うためです。
  「1kW増やすと22万円増えるが、それで電気代削減・売電がいくら増えるか」で最適容量が決まります。
- 蓄電池・V2H の費用は太陽光の容量選びに影響しないため、参考値として別に扱います。

## 6. 推奨容量の決め方

パネルを1枚から屋根の上限まで1枚ずつ増やし、全ケースを計算して次の4つの基準を出します。

| 基準 | 定義 |
|---|---|
| **経済性** | 評価期間（既定20年）の累計収支が最大になる容量。最大値の95%以上になる範囲も表示 |
| **ネットゼロ** | 年間の発電量が年間の消費量（EV充電を含む）以上になる最小の容量 |
| **屋根上限** | 発電に適した面（既定で北向きは除外）に載る最大枚数 |
| **停電対策ライン** | 12月の曇りの日でも、停電時に必要な電力量（冷蔵庫・照明・通信＋ペット用エアコンなど）を日中に発電できる最小の容量 |

「提案の目的」で採用する基準を選びます。

- 経済性重視（既定）→ 経済性の容量
- 自給重視 → ネットゼロの容量（屋根に載らなければ屋根上限）
- 屋根いっぱい → 屋根上限
- 「停電対策を優先」にチェック → 上記が停電対策ラインより小さければ停電対策ラインまで引き上げ

### 現在の制度での傾向

2025年10月からの初期投資支援スキーム（最初の4年間 24円）により、余剰電力の価値が上がっています。
1kWあたりの追加費用が20万円台前半なら、**屋根に載るだけ載せるのが経済的にも最適**になるケースが多くなります。
追加費用が高い（狭小屋根・寄棟で割付けが難しい等）と、経済性の最適容量は小さくなります。
画面の「累計収支カーブ」で、どこから伸びが鈍くなるかを見せると納得感が出ます。

## 7. 停電・災害時

- 蓄電池・V2H がない場合、停電時はパワコンの**自立運転コンセント（最大1.5kVA）**から昼間のみ使えます。
- 蓄電池（実効容量×90%）・V2H（EV電池の80%×効率90%）があれば、「太陽が出なくても何日分の必要電力をまかなえるか」を表示します。
- ペットがいる家庭では、24時間エアコン1台分（夏の最も多い月の1日分）を必要電力に含めると、蓄電池の容量選びの根拠になります。

---

## 8. 考慮していないこと（お客様への注意事項）

- 周辺の建物・樹木・電柱による影（屋根面ごとの「影%」で手動入力）
- 積雪（「積雪による冬季損失%」で手動入力。12〜3月に適用）
- 出力制御、停電、機器の故障・交換費用（パワコンは15年前後で交換が一般的）
- 補助金（入力の固定費から差し引いてください）
- JPEA ガイドラインの注記どおり、推定発電量には影・積雪・経年劣化・出力制御等の影響は含まれません（経済性計算では劣化0.5%/年を考慮）。
