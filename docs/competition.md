# 競合の調査と「口コミで広がるか」の見直し

調査日：2026-09-30

## 1. 似たサービスはあるか

| ツール | 無料で登録不要のもの | 有料・登録制のもの | ふくしのおたすけ帳の違い |
|---|---|---|---|
| 放デイ・児発の個別支援計画 | **エデアル**：特性・苦手なことなどを細かく選び、ChatGPT等に貼る「依頼文」を作る。計画書そのものは作らない | HUG、デイロボ、co-mii、コノベルなど（請求ソフトやAIの有料サービス） | 計画書そのものが、国の参考様式どおりにその場でできる。AIのアカウントがなくても使える。依頼文のコピーもできる |
| 支援プログラム | **見当たらない** | co-mii、デイロボなど | 手引きの①〜⑫どおりに作れる、無料では唯一のツール。ホームページ掲載用HTMLまで出る |
| 障害福祉（就労系など）の個別支援計画 | 依頼文の例を載せた記事（ERABERU など）、プロンプト共有サイト | Maa2、AURA就労支援など（録音→書類を作るAI） | 基準の記載事項どおりの計画書がその場でできる |
| 介護の事故報告書 | ChatGPTのGPTs（事故報告アシスタント）、例文記事、テンプレート配布（ふくしの素材館など） | CareViewer、むすぼなAIなど | 標準様式の9項目どおり。要因（本人・職員・環境）を選ぶと再発防止策が入る。アカウント不要 |
| 連絡帳 | 例文記事は多いが、**ツールは見当たらない** | 連絡帳アプリ（事業所で契約） | 毎日使える「文例メーカー」を追加（今回） |

**結論**：同じ「無料・登録不要」で、しかも**書類そのものが国の様式どおりにできる**ものは、調べた範囲では見当たらなかった。いちばん近いのはエデアル（依頼文を作るだけ、児童支援のみ）。

## 2. 口コミで広がるか（正直な見立て）

**広がりにくい理由**
- 計画書は半年に1回。使う頻度が低いと、話題にのぼりにくい。
- 「ツールで書いた」と言いにくい人もいる。
- 検索で来た人は、使ったら閉じて終わりになりやすい。

**広がりやすくする打ち手（今回実装したもの）**
| 打ち手 | ねらい |
|---|---|
| **連絡帳の文例メーカー**（毎日使う） | 毎日開くツールがあると、休憩室の雑談で話題になり、ブックマークされる |
| **下書きをリンクで共有**（選んだ課題・要因だけをURLにする。個人情報は含まない） | 児発管が「この課題でたたき台作ったから見て」と同僚に送れる。事業所の中で自然に広がる |
| **「事業所みんなで書き方をそろえる」という打ち出し** | 「楽をするツール」ではなく「チームで質をそろえる道具」として、管理者が職員に勧めやすくする |
| **紹介チラシ（A4・QRコード）** | 事務所・休憩室に貼る、研修や会議で配る。紙で回る業界向けの口コミ |
| **特性から課題の候補を出す**（ASD・ADHDなど） | エデアル並みの入口の細かさ。初めての人でも迷わない |
| 共有ボタン（LINE・X・URL） | すでに実装済み |

**それでも残る課題**
- 最初の利用者をどう集めるか：SNS（`docs/sales/sns-posts.csv`）、Instagram（保育士・児発管の発信者が多い）、自治体の集団指導の時期（年度初め）に合わせた投稿。
- 信頼：運営者が誰か分からないサイトは現場で勧めにくい。公開時に運営者名と問い合わせ先を必ず載せる。
