# 次のサービスの検討：課題と解決策

作成日：2026-09-29

---

## 1. 選ぶ条件

1つ目のサービス（放デイ・児発の個別支援計画）で見えた「勝ち筋」を、そのまま使える業種を探す。

1. **国の決まりで書類が必須**で、書かないと減算・行政指導になる（お金を払う理由がある）
2. **現場の職員が自分で検索する**（営業しなくても検索から人が来る）
3. **国の様式や記載例がある**（それに沿った文例と様式を作れる）
4. **今ある資産を使い回せる**（文例データ → 無料ツール → 文例ページ → 有料Excel、という作り）
5. 建築系は除く

| 候補 | 書類の頻度 | 減算・指導の圧力 | 検索する人 | 競合 | 資産の使い回し | 評価 |
|---|---|---|---|---|---|---|
| **A. 介護の事故報告書・ヒヤリハット** | 事故・ヒヤリのたびに発生（毎週〜毎日） | 市町村への事故報告は義務。国の標準様式あり（令和3年） | 介護職員が自分で「事故報告書 転倒 例文」などと検索 | テンプレートの無料配布、汎用AIチャットはある。**種別ごとの文例と、原因分析・再発防止策まで組み立てる専用ツールは少ない** | ◎ そのまま使える | **◎ 本命** |

## 3. 本命：介護の事故報告書・ヒヤリハット

### 3-1. 現場の課題

| 課題 | 誰が困っているか | 深刻さ |
|---|---|---|
| 事故のたびに報告書を書く。「何をどこまで書けばいいか」が分からない | 介護職員（夜勤明けに書くことも多い） | 高 |
| 「原因分析」「再発防止策」が毎回「見守りを強化する」になり、上司や行政に突き返される | 介護職員・リーダー | 高 |
| 市町村の様式（国の標準様式）に合わせて書き直す手間 | 管理者・生活相談員 | 中 |
| ヒヤリハット・事故を集計して、事故防止委員会で報告・分析する | 委員会の担当者 | 中〜高（施設は委員会が定期開催） |
| 家族への説明。書き方ひとつでトラブルになる不安 | 管理者 | 高 |

### 3-2. 国の標準様式（厚生労働省 令和3年3月「介護保険施設等における事故の報告様式等について」）
記載する要素は次の9つ。
1. 事故状況（程度）
2. 事業所の概要
3. 対象者
4. 事故の概要（事故の種別：転倒・転落・誤嚥・窒息・異食・誤薬・与薬もれ等・その他）
5. 事故発生時の対応
6. 事故発生後の状況（家族への報告・関係機関への連絡など）
7. 事故の原因分析（本人要因・職員要因・環境要因）
8. 再発防止策（手順の変更・環境の変更・その他の対応、評価時期と結果）
9. その他特記事項

→ いまのサービスと同じく「**国の様式どおりの項目で、文例から下書き**」が作れる。

### 3-3. 解決策（1つ目のサービスと同じ型）

| 段階 | 内容 | 価格 |
|---|---|---|
| ① 無料ツール | 事故の種別（転倒・転落・誤嚥・誤薬・異食・離設・皮膚剥離・内出血など）と状況を選ぶと、国の標準様式の項目で下書きができる。**原因分析を「本人・職員・環境」で選択式にし、再発防止策の文例を要因に合わせて出す**（「見守り強化」だけで終わらせない） | 無料 |
| ② 文例ページ（SEO） | 「転倒 事故報告書 例文」「誤薬 再発防止策」など、種別×場面ごとのページ（30〜50ページ） | 無料 |
| ③ 有料Excel | 事故・ヒヤリハット台帳（入力すると月別・種別・時間帯別に自動集計・グラフ化）＋報告書様式（プルダウンで文例）＋事故防止委員会の月次報告の様式 | 4,980円前後 |
| ④ 横展開 | 同じ台帳を障害福祉（放デイの既存顧客）・保育向けに。第2弾（義務化研修・委員会）の「事故防止委員会・研修」とつなげる | ― |

### 3-4. 市場の大きさ
- 介護サービスの事業所は、訪問介護だけで3万を超え、通所介護・訪問看護・短期入所生活介護もそれぞれ1万以上、地域密着型通所介護が約2万（厚生労働省「介護サービス施設・事業所調査」令和5年）。
- 報告書を書くのは現場の介護職員全員。**検索する人の数は、放デイの児発管より桁違いに多い**。

### 3-5. 注意点
- 事故報告の提出先・様式・報告の範囲は**市町村ごとに違う**。ツールでは「国の標準様式に沿った下書き」と明記し、提出前に市町村の様式を確認してもらう。
- 個人情報（利用者名・病名など）は入力させない設計（1つ目と同じく、ブラウザの中だけで処理）。
- 医療的な判断（受診の要否など）はツールで示さない。

## 4. 第2弾の候補：介護・障害福祉の義務化研修・委員会

- 施設系は、身体拘束・感染症・BCP・事故防止・虐待の研修がそれぞれ「年2回以上＋新規採用時」、身体拘束の委員会は3か月に1回以上、感染症の委員会はおおむね3か月に1回以上（名古屋市「研修回数等基準一覧」）。1年中、研修資料と議事録づくりが続く。
- 無料のひな形は多いので、勝ち筋は「**研修をそのまま開ける一式**」（読み上げ原稿つきスライド・確認テスト・参加記録）と「**議事録の文例**」。
- 事故報告書のサービスで集めた介護事業所の読者に、そのまま案内できる。

---

## 5. 進め方（提案）

| 週 | やること |
|---|---|
| 1週目 | 事故の種別（10種）× 原因（本人・職員・環境）× 再発防止策の文例データを作る。国の標準様式の原本を読み込み、項目を確定 |
| 2週目 | 無料の下書きツールと文例ページ（30ページ〜）を作り、1つ目のサイトとは別ブランドで公開 |
| 3週目 | 有料Excel（台帳・自動集計・報告書様式）を作り、BOOTHで販売開始 |
| 4週目〜 | 検索順位とアクセスを見ながら文例を追加。第2弾（研修・委員会）の準備 |

1つ目のサービスの仕組み（ビルド・Excel生成・PDF・販売ページ・商品画像）を使い回せるので、1つ目より短い期間で公開できる見込み。
