# AIで月10万円以上を稼ぐ仕組み：戦略と実行プラン

前提：すでに「記事サイト＋アフィリエイト＋自動化」を運用中。
目標：それ以外の収益源で、**3か月以内に月10万円**、その後それを月30万円規模へ伸ばす。

---

## 1. 結論（推奨する組み合わせ）

| 役割 | 方法 | 月10万円までの目安 | 性質 |
|---|---|---|---|
| **柱A（短期の現金）** | 中小企業・個人事業主向け「AI業務自動化」の構築代行 ＋ 月額保守 | 1〜2か月 | 受託 → 月額課金に移行 |
| **柱B（ストック化）** | 柱Aで作った仕組みをテンプレート／ツール化して販売（既存サイトの読者に売る） | 3〜6か月 | デジタル商品（自動販売） |
| 柱C（将来の選択肢） | 売れたテンプレートを小さなSaaSにする | 6〜12か月 | 月額課金 |

**理由**

- 「AIで記事量産」や「AI動画量産」は参入者が多いうえ、プラットフォーム側が規制を強めている（下記4章）。一方、**AIで他人の業務を自動化する仕事は需要が伸びているのに、作れる人が少ない**。
- あなたはすでに自動化を回しているので、スキル面での持ち出しが最も少ない。
- 受託は「1件取れれば即入金」。月10万円は **初期構築1件（10〜20万円）** か **保守契約3社（各3〜4万円）** で届く。
- 受託で「何が売れるか」を実際の顧客から学べる。それをテンプレート化すれば、柱B・柱Cで売る商品を当てずっぽうで作らずに済む。

---

## 2. 候補の比較（なぜ他の方法を主軸にしないか）

| 方法 | 月10万の現実性 | 初期コスト | 主なリスク | 評価 |
|---|---|---|---|---|
| AI業務自動化の受託＋保守 | 高い（最速） | ほぼ0円 | 労働集約になりやすい → 保守の月額化とテンプレート化で対処 | ◎ |
| 自作テンプレ／ツール販売（note・Brain・BOOTH・Gumroad・自サイト） | 中（集客次第） | ほぼ0円 | 最初は売れない → 既存サイトの流入で補う | ○（柱Aと組み合わせれば◎） |
| マイクロSaaS | 中〜低（時間がかかる） | 数千円／月〜 | 開発・サポートの負担、解約 | ○（柱Aの後に） |
| 有料ニュースレター／メンバーシップ | 中〜低 | ほぼ0円 | 読者100人規模が必要 | △ |
| AIショート動画／YouTube量産 | 低 | 小 | YouTubeは量産・反復的なコンテンツを収益化の対象外にしている | × |
| AI生成Kindle本の量産 | 低 | 小 | 単価が低い。AI生成であることの申告が必要 | × |
| AI記事サイトの追加量産 | 低下傾向 | 小 | Googleの「大量生成コンテンツの不正使用」ポリシー | 現状維持まで |

## 3. 柱A：AI業務自動化代行の具体設計

### 3-1. 狙う顧客（1つに絞る）

「毎日同じ文章を書いている」「同じ情報を転記している」業種がおすすめ。

- 美容室・整体・歯科・飲食店：Googleの口コミへの返信文、予約リマインド、Instagramの投稿文
- 不動産仲介：物件紹介文の作成、ポータルサイトへの転記、問い合わせへの一次返信
- 士業（税理士・社労士・行政書士）：問い合わせの振り分け、議事録、定型書類の下書き
- EC・物販：商品説明文、レビューの要約、問い合わせへの返信テンプレート
- 採用中の中小企業：求人票の作成、応募者対応の自動化

> 最初は **1業種×1つの悩み** に絞る。例：「美容室向け：Google口コミへの返信を自動で下書き」。
> 絞るほど営業文・事例・テンプレートを使い回せます。

### 3-2. サービスメニューと価格（目安）

| プラン | 内容 | 価格 |
|---|---|---|
| 無料診断（30分） | 業務のヒアリング、自動化できる箇所の洗い出し | 0円（見込み客を集める入口） |
| スポット構築 | 1業務の自動化（例：口コミ返信の下書き → Slack／LINEに通知） | 5万〜15万円 |
| 標準構築 | 2〜3業務の自動化＋操作マニュアル＋研修1回 | 15万〜30万円 |
| 月額保守・改善 | 不具合対応、プロンプト改善、月1回の改善提案 | 2万〜5万円／月 |

**月10万円の計算例**

- 例1：スポット構築 1件（10万円）→ 1か月目で達成
- 例2：保守 3社×3.5万円 ＝ 10.5万円（毎月入る安定収入）
- 例3（3か月目の目標）：保守5社（17.5万円）＋ 新規構築1件（10万円）＝ 27.5万円

### 3-3. 使う技術（あなたの自動化スキルをそのまま使う）

- ノーコード：Make／Zapier／n8n（自分のサーバーで動かせば安い）
- Googleまわり：Google Apps Script（スプレッドシート・Gmail・フォーム）
- AI：Claude API など（文章の生成・分類・要約・情報の抽出）
- 通知先：LINE公式アカウント、Slack、Chatwork、メール

**API料金は顧客のアカウントで払ってもらう** か、保守料に含めて上限を決めておく（原価割れを防ぐ）。

### 3-4. 集客（お金をかけない順）

1. **既存サイトで募集する**：アフィリエイト記事の最後や専用ページに「業務自動化の相談」への導線を置く
2. **Xやnoteで作ったものを公開する**：「〇〇業の△△を自動化した」をデモ動画付きで毎週1本
3. **ココナラ／ランサーズに出品する**：最初の実績と口コミを作る場所として使う（手数料は高いので、実績ができたら直接契約へ）
4. **地元の店舗に直接声をかける**：Googleマップで口コミへの返信が滞っている店を探し、改善例を添えて連絡
5. **知人の紹介**：最初の1件は、ほぼ無料でもいいので事例づくりを優先

### 3-5. 営業メッセージのテンプレート

```
〇〇様

突然のご連絡失礼します。△△と申します。
AIを使った店舗業務の効率化をお手伝いしています。

御社のGoogleマップの口コミを拝見し、丁寧に返信されている点が印象的でした。
一方で、毎回の返信作成にお時間がかかっているのではと思い、ご連絡しました。

口コミが入ると、AIが返信文の下書きを自動で作り、LINEにお届けする仕組みを作っています。
（確認して送るだけなので、1件あたり10秒ほどで済みます）

実際に御社の口コミ3件で作った返信の下書きを添付します。
ご興味があれば、15分ほどオンラインでデモをお見せできます。

△△
```

ポイント：**相手の実データで作った成果物を先に渡す**（AIなので1件数分で作れる）。

### 3-6. ヒアリングシート（無料診断で聞くこと）

- 毎日・毎週くり返している作業は？（作業名／回数／1回あたりの時間）
- その作業で使っているツールは？（Gmail、スプレッドシート、LINE、予約システムなど）
- 間違えると困るもの（金額・個人情報・法的な表現）は？
- 誰が最終確認をするか？（AIに全部任せず、人が確認する流れにする）
- 月額の予算感は？

## 4. 柱B：テンプレート／ツールの販売（ストック型）

柱Aで2〜3件作ると、「どの顧客にも使える部分」が見えてきます。それを商品にします。

| 商品例 | 形式 | 価格 |
|---|---|---|
| 〇〇業向け AI口コミ返信の自動化キット（GAS＋プロンプト＋手順書） | ダウンロード商品 | 4,980〜9,800円 |
| 業種別プロンプト集＋業務フローの設計図 | PDF／Notion | 1,980〜4,980円 |
| 自動化を自分で作るための動画講座＋テンプレート | 動画＋ファイル | 19,800〜49,800円 |

**計算例**：4,980円 × 月20本 ＝ 約10万円（手数料を引く前）。

**販売先**
- 自分のサイト（Stripe・BASEなど）：手数料が最も安い。既存のアフィリエイト読者に案内できる
- note／Brain：集客力はあるが、手数料が高め
- 買った人の一部が「自分で作るのは面倒」→ 柱Aの構築依頼につながる（**商品と受託が互いに集客し合う**）

## 5. 既存のアフィリエイト事業にも効く改善

- 記事の読者に「自分の商品」または「相談窓口」を案内する：アフィリエイトは報酬率が数%〜の商材が多い。自分の商品ならほぼ全額が利益
- 訪問者のメールアドレスを集める（無料テンプレートと引き換え）：Googleの検索順位が変わっても売上が消えない資産になる
- AI記事の量産ペースは上げず、**実際に使った体験・画像・独自データ**を足して記事の質を上げる

---

## 6. 守るべきルール（収益を失わないために）

- **Google検索**：大量生成で検索順位を操作する目的のコンテンツは、スパムポリシー違反。記事サイトの量産は、品質を保つ前提で
- **YouTube**：量産型・反復的なコンテンツは、収益化（YouTubeパートナープログラム）の対象外
- **ステマ規制（景品表示法、2023年10月施行）**：アフィリエイト記事には「広告」「PR」の表示が必須
- **特定商取引法**：自社サイトで商品を売るなら、特定商取引法に基づく表記が必要
- **受託の契約**：業務委託契約書で「成果物の範囲・修正回数・保守の内容・API費用の負担・個人情報の扱い」を決める
- **個人情報**：顧客データをAIに渡すときは、APIの規約（学習に使われるかどうか）と顧客の同意を確認する
- **売上の目安**：副業の所得が年20万円を超えると確定申告が必要（会社員の場合）
